# sekou-manual-editor

## 概要
施工計画書自動作成ツール。Next.jsベースのWebアプリ。

## 主な機能
- 施工計画書作成
- データ保存（localStorage）
- データエクスポート/インポート（ある場合のみ記載）

## 技術スタック
- Next.js
- React
- TypeScript（使用していれば）

## セットアップ

```bash
git clone https://github.com/adchrk1031/sekou-manual-editor.git
cd sekou-manual-editor
npm install
npm run dev
```
