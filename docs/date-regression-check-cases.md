# 日付回帰チェック仕様（Step 8）

## 目的
- 日付整形ロジックの退行（+1日ズレ、形式崩れ）をメニュー実行で即時検知する。

## チェック対象
- `toDateStr_`
- `toDateTimeStr_`
- `formatTimeValue_`
- `parseTimeToMinute_`
- `normalizeProjectDateFields_`

## 代表ケース
- `2026-04-24` -> `2026/04/24`
- `2026/4/5` -> `2026/04/05`
- `2026-04-24 10:30` -> `2026/04/24 10:30`
- `2026-04-24T10:30:00` -> `2026/04/24 10:30`
- `9:05` -> `09:05`
- `2026/4/24 9:00` -> `2026-04-24 09:00`（保存正規化）

## 合格条件
- 失敗数 `0`
- 失敗がある場合は、修正完了までPDF出力運用を停止
