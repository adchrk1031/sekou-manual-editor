# 現場向けレスポンシブ改善ロードマップ

## 目的
- 現場でスマホから片手でも迷わず入力できること
- 他業者へ共有しても、担当外の案件や不要な操作で事故が起きにくいこと
- 電波が弱い場所でも「保存されたか」「同期されたか」が分かること

## 直近の実装方針
### Phase 1
- スマホ固定アクションバー
  - 保存
  - PDF出力
  - 未入力一覧
  - メニュー
- 保存状態の見える化
  - 端末保存時刻
  - クラウド同期時刻
  - オフライン状態
- 未入力一覧パネル
  - セクション別に不足項目を表示
  - タップで該当入力へジャンプ

### Phase 2
- 現場モード
  - 基本情報
  - 工事項目
  - 日程
  - 写真
  - 案内文
- スマホでは 1 セクションずつ入力する導線を優先
- PDF単位ではなく、入力作業単位のタブに寄せる

### Phase 3
- 案件担当制
  - `Project` に担当者ID配列を保持
  - 一覧の初期表示は「自分の担当案件」
  - 管理者のみ全件表示可能
- 案件共有
  - 案件ごとに閲覧者 / 編集者を設定
  - 全体ロールより狭い権限で渡せるようにする

### Phase 4
- FAQ / 定型文プルダウン
  - 停電案内文の注意文テンプレ
  - 管理会社別の定型文
  - 夜間工事など条件別の差し込み
- CSV 取込差分確認
  - どの項目が案件へ反映済みか
  - どこが未反映か

## UI/UX 原則
- 主要操作は画面下で完結させる
- 1 画面に全部見せず、スマホでは工程を分割する
- 保存や同期は自動で行い、状態だけ常に見せる
- 入力漏れは「警告」ではなく「次にやること」として見せる
- 写真はファイル選択より撮影導線を前に出す

## データと権限の前提
- 業務日付は `YYYY-MM-DD`
- 業務時刻は `HH:mm`
- 既存 localStorage key は維持
- 共有保存は `normalizeProject()` を通す
- 担当制を入れる場合も既存ロール
  - `system_admin`
  - `admin`
  - `editor`
  - `viewer`
  は残し、案件単位権限を上乗せする
