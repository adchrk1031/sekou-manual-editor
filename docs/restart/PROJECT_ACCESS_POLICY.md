# 案件アクセス方針

更新日: 2026-05-27

## 目的

第2段階の運用安全として、案件ごとの閲覧対象と編集対象を明確にする。

## 基本ルール

- 案件は `shared` と `private` の 2 種類で扱う
- すべての案件に `ownerUserId` と `ownerUserName` を持たせる
- 所有者情報が不足している旧案件は、正規化時に空文字互換を維持しつつ既存表示を壊さない

## 閲覧ルール

### shared

- 承認済みかつ active なユーザーは閲覧可能
- `viewer` も閲覧可能
- `admin` / `system_admin` も閲覧可能

### private

- 所有者本人は閲覧可能
- `admin` / `system_admin` は閲覧可能
- それ以外の一般ユーザーには一覧表示しない

## 編集ルール

### shared

- `editor` / `admin` / `system_admin` が編集可能
- `viewer` は編集不可
- 既存の編集ロックに従う

### private

- 所有者本人が編集可能
- `admin` / `system_admin` が編集可能
- `viewer` は編集不可
- 所有者以外の一般ユーザーは編集不可
- 既存の編集ロックに従う

## アクセス設定変更

- `shared <-> private` の切替は、所有者本人または管理者のみ
- 切替時は監査ログ `project_access_update` を残す

## CSV から生成される案件

- CSV取込や案内文起点で生成される新規案件は `shared` を既定値とする
- 手動で新規作成した案件は `private` を既定値とする

## UI 表示

- 保存状態カードの近くに `案件アクセス` を常時表示する
- 表示内容:
  - `共有案件` / `自分専用`
  - 所有者名
  - 説明文
  - 所有者または管理者向けの切替ボタン

## 注意点

- これは案件単位の最低限の閲覧 / 編集整理であり、将来的な部署別・現場別ACLではない
- DB 正本化の完了後は、API 側でも同じ判定を持つ必要がある
