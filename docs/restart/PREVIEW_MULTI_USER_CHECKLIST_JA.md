# Preview Multi-User Checklist

## 目的

施工計画書自動作成ツールを preview 環境で 2 アカウント以上使い、

- 全体共有が効いているか
- 同一案件ロックが効いているか
- 別案件並行作業が可能か
- PDF 出力が可能か
- 別ユーザー更新の自動再読込が効くか

を確認するための手順です。

## 前提

- 同じ preview URL を使う
- 2 つ以上のブラウザプロファイル、またはシークレットウィンドウを用意する
- 利用者 A / B の両方が `approved` かつ `active` のユーザーであること
- `/tracking` のユーザー一覧で対象アカウントが見えること
- 同じ案件を確認するときは `/editor` を使う
- `/editor-next` は分割 preview 用なので、PDF の最終確認は `/editor` を使う

## 確認 1: ユーザー共有

1. A で `/tracking` を開く
2. ユーザー一覧に B が表示されることを確認する
3. B でログインし、同じ `/tracking` を開く
4. A で追加したユーザー、承認変更、利用状態変更が B 側でも見えることを確認する

期待結果:

- ユーザー一覧が共有される
- セッション自体は共有されない

## 確認 2: 同一案件ロック

1. A で `/editor` を開き、既存案件 `PJ-LOCK-A` を選ぶ
2. A が物件名か住所を編集して保存完了まで待つ
3. B で同じ `PJ-LOCK-A` を開く
4. B 側で「他のユーザーが編集中」の表示が出ることを確認する
5. B 側で以下を試す
   - 基本情報の変更
   - 履歴保存
   - 履歴復元
   - 案件削除

期待結果:

- B は読み取り専用になる
- 保存系操作は止まる
- A がタブを閉じるか 2 分以上 heartbeat が切れると、B 側が編集可能へ戻る

## 確認 3: 別案件並行作業

1. A が `PJ-A` を開く
2. B が `PJ-B` を開く
3. A は `PJ-A` を編集して保存する
4. B は `PJ-B` を編集して保存する
5. A / B それぞれで PDF 出力を試す

期待結果:

- 別案件ならロックは干渉しない
- A と B は同時に別案件を作業できる
- A / B ともに PDF 出力できる

## 確認 4: 自動再読込

1. A が `PJ-SYNC` を開いて物件名を変更し、保存完了まで待つ
2. B も `PJ-SYNC` を開いたまま待つ
3. B は画面を触らず最大 30 秒待つ
4. 30 秒以内に反映しない場合、タブを一度非表示にして戻す

期待結果:

- B 側に更新内容が自動反映される
- 少なくとも 30 秒以内、またはタブ再表示で最新内容を読める

## 確認 5: PDF 出力ポリシー

1. A が編集中の `PJ-PDF` を開く
2. B が同じ `PJ-PDF` を開いてロック表示を確認する
3. B で PDF 出力を押す

期待結果:

- PDF 出力自体はできる
- ただし B は読み取り専用扱いなので、案件の更新履歴や出力回数は編集者としては記録されない

## 補足

- 「案件が消えた」を防ぐ観点では、同一案件ロックと定期 pull により、同時上書きと stale 表示のリスクを下げる
- それでも完全なリアルタイム共同編集ではない
- FAQ 機能を将来追加する場合は、このチェックリストの各期待結果をそのまま FAQ 候補へ流用できる
