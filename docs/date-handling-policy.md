# 日付取り扱い設計方針（Step 1: 設計確定）

## 採用方針（唯一の正本）
- 業務日付は `YYYY-MM-DD` 文字列を唯一の正本とする。
- 正本の意味は「Asia/Tokyo の暦日」であり、時刻・タイムゾーン情報を含めない。

## 適用範囲
- 対象: 工事日、停電開始日、停電終了日、工程表の開始日・終了日。
- 非対象: 監査ログ時刻、作成日時、最終ログイン時刻などの時刻メタ情報。

## データ型ルール
- 日付: `YYYY-MM-DD`（例: `2026-04-24`）
- 時刻: `HH:mm`（例: `14:30`）
- 日時は保存しない。必要な表示は `date + time` を表示時に組み立てる。

## 禁止事項
- 業務日付を `Date` 型で保存しない。
- 業務日付を `new Date(...)` に変換して再保存しない。
- PDF出力で業務日付を `Date` 経由でフォーマットしない。

## 受け入れ基準
- 4/24 を入力した業務日付が 4/25 に変化しない。
- 停電終了日が自動で翌日に繰り上がらない（明示操作時を除く）。
- 画面表示、保存値、PDF表示の業務日付が一致する。
